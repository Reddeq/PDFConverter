# PDFConverter

**Batch PDF-to-Image Converter with Reference Image Properties**

Утилита на Python для пакетного преобразования PDF в изображения с автоматическим определением технических параметров по оригинальным графическим файлам.

Разработана для автоматизации обработки изображений в переводческих и DTP-проектах, где необходимо сохранять размеры, разрешение и формат оригиналов.

## Зачем создан проект

В процессе локализации графических материалов исходные изображения подготавливаются к переводу через PowerPoint. После перевода необходимо получить новые PNG/JPG-файлы, технические параметры которых соответствуют оригиналам.

Для некоторых заказчиков это критически важно: изменение размеров изображения или его разрешения может нарушить работу программного обеспечения, в котором используются эти файлы.

Ранее экспорт выполнялся вручную. При обработке крупных заказов, содержащих сотни изображений, это занимало значительное время.

PDFConverter автоматизирует этот процесс.

## Возможности

- Пакетная конвертация PDF в изображения.
- Автоматический поиск соответствующих исходных изображений по именам файлов.
- Определение размера изображения в пикселях.
- Определение разрешения (DPI).
- Определение формата исходного изображения.
- Преобразование PDF с использованием Poppler.
- Масштабирование изображений алгоритмом LANCZOS.
- Сохранение в PNG, JPEG, BMP и TIFF.
- Проверка размеров и DPI полученных файлов.
- Вывод результатов обработки и сообщений об ошибках.
- Интерактивный выбор папок через стандартные диалоговые окна Windows.

## Принцип работы

1. Пользователь подготавливает PDF-файлы с переведённым содержимым.
2. Указывает папку с PDF и папку с оригинальными изображениями.
3. Программа сопоставляет PDF с исходными изображениями по именам файлов.
4. Считывает технические параметры оригиналов.
5. Конвертирует PDF в соответствующий графический формат.
6. Масштабирует результат до необходимых размеров.
7. Сохраняет выходные изображения и проверяет размеры и DPI.

**Пример:**

Оригинал: `diagram.png`

Переведённый документ: `diagram-ru-en-P1.pdf`

Результат: `diagram-ru-en-P1.png`

Формат, размеры в пикселях и DPI результата определяются по `diagram.png`.

## Установка и запуск

Проект ориентирован на Windows.

Для запуска из исходного кода необходимы Python, библиотеки Pillow и pdf2image, а также Poppler.

Установка Python-зависимостей:

`py -m pip install Pillow pdf2image`

Исполняемые файлы Poppler должны находиться в каталоге:

`PDFConverter/poppler/Library/bin`

Запуск из корня репозитория:

`py PDFConverter/PDFConverter.py`

После запуска программа предложит выбрать папки с PDF и исходными изображениями.

## Ограничения

- Программа принимает PDF, а не PPT/PPTX напрямую.
- Сопоставление файлов зависит от их имён.
- Поиск исходных изображений выполняется в выбранной папке без обхода вложенных каталогов.
- Проверяются размеры в пикселях и DPI; полная идентичность метаданных или содержимого изображений не гарантируется.
- При отсутствии DPI в метаданных исходного изображения используется значение 72 DPI.
- Существующие выходные файлы могут быть перезаписаны.
